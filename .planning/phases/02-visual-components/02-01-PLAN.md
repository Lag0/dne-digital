<task id="02-01-T2" type="auto">
  <name>Configurar SVGR via turbopack.rules e criar type declaration</name>
  <files>
    - next.config.ts
    - src/types/svg.d.ts
  </files>
  <action>
    AGUARDAR conclusao de 02-01-T1 antes de executar.

    1. Atualizar next.config.ts para adicionar bloco turbopack com rules para SVG:

    ```typescript
    import type { NextConfig } from "next";

    const nextConfig: NextConfig = {
      reactCompiler: true,
      turbopack: {
        rules: {
          '*.svg': {
            loaders: ['@svgr/webpack'],
            as: '*.js',
          },
        },
      },
      images: {
        remotePatterns: [
          { protocol: "https", hostname: "images.unsplash.com" },
          { protocol: "https", hostname: "media.discordapp.net" },
          { protocol: "https", hostname: "api.qrserver.com" },
        ],
      },
    };

    export default nextConfig;
    ```

    IMPORTANTE: Usar `turbopack.rules` — NAO usar `webpack()` override. Em Next.js 16, Turbopack e o bundler padrao para `next dev` e `webpack()` nao e executado durante desenvolvimento.

    2. Criar diretorio src/types/ (se nao existir) e arquivo src/types/svg.d.ts:

    ```typescript
    declare module '*.svg' {
      import { FC, SVGProps } from 'react';
      const content: FC<SVGProps<SVGSVGElement>>;
      export default content;
    }
    ```

    3. Se a cor mint confirmada no T1 for DIFERENTE de #8CD6BF, atualizar globals.css:
       - Linha: `--color-dne-mint: #8CD6BF;`
       - Substituir pelo hex exato confirmado
       - Manter dentro do bloco `@theme inline {}` existente — nao criar segundo bloco

    NAO alterar apple-wallet.tsx — o componente usa SVG inline (nao import de arquivo .svg) e nao e afetado pelo turbopack rule.
